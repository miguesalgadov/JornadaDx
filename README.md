# JornadaDX Landing Page

Landing page estática lista para subir a hosting.

## Archivos

- `index.html`: estructura HTML.
- `styles.css`: estilos responsive.
- `script.js`: menú móvil y animaciones suaves.
- `assets/logo.svg`: logo vectorial JornadaDX.
- `assets/favicon.svg`: favicon.

## Cómo subirla

Sube todo el contenido de esta carpeta al directorio público de tu hosting, por ejemplo:

- cPanel: `public_html/`
- Netlify: arrastra la carpeta completa
- Vercel: importa la carpeta como proyecto estático
- GitHub Pages: sube los archivos al repositorio
